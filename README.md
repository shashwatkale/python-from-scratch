# Python From Scratch

> Learn Python by building. Free. Open source. No fluff.

An open-source, hands-on Python curriculum that takes you from your first `print()` statement to production-ready applications.

---

## Start Here

If you have never written Python before, start at:

**[Phase 00 — Getting Started](curriculum/00-getting-started/)**

If you already know the basics, jump to the phase that matches your level using the [Roadmap](ROADMAP.md).

## How to Run Examples

```bash
# Clone the repository
git clone https://github.com/your-username/python-from-scratch.git
cd python-from-scratch

# Create a virtual environment
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate

# Install dev dependencies
pip install -r requirements.txt

# Run any example
python curriculum/01-python-basics/01-variables/example.py

# Run tests
pytest
```
